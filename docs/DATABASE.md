# Data model & database schema

Content is stored as JSON in `/data` and read on the server through `lib/data.ts`. Pages never import JSON directly. To move to Supabase or PostgreSQL, create the tables below, import the JSON, and change only the functions in `lib/data.ts`.

## Files

| File | Entity | Maintained by |
|---|---|---|
| `data/vehicles.json` | Vehicles (full records) | Generated by `scripts/build_data.py` |
| `data/vehicle-index.json` | Slim vehicle rows for the catalogue (`/api/vehicles`) | Generated |
| `data/brands.json` | In-game brands and their wiki-stated real-life counterpart | Generated |
| `data/limited-log.json` | Limited, event and drop vehicles per update version | Generated |
| `data/dealerships.json` | Dealerships | Hand-curated |
| `data/updates.json` | Documented updates and changelogs | Hand-curated |
| `data/sources.json` | Source register | Hand-curated |
| `data/social.json` | Social links | Hand-curated |
| `data/gamepasses.json` | Official game passes | Hand-curated, from the Roblox API |
| `data/regions.json`, `data/seasonal-maps.json` | Map regions | Hand-curated |
| `data/timeline.json` | About-page milestones | Hand-curated |
| `data/guides.json` | Guides, written as typed content blocks | Hand-curated |
| `data/game.json` | Game facts and stats snapshot | Hand-curated, from the Roblox API |

TypeScript definitions for every entity are in `lib/types.ts`. `npm run validate:data` checks ids, enums, dates and every relational reference, and it runs automatically before each build.

## PostgreSQL schema (Supabase-compatible)

```sql
create type verification as enum ('official', 'community', 'partial', 'unverified');
create type availability as enum ('dealership', 'event', 'minigame-box', 'removed', 'unlisted');
create type update_status as enum ('released', 'announced', 'upcoming', 'rumored', 'unverified');

create table sources (
  id               text primary key,
  title            text not null,
  url              text not null,
  source_type      text not null check (source_type in ('official', 'official-archived', 'community')),
  publisher        text,
  publication_date date,
  access_date      date not null,
  reliability      verification not null,
  notes            text
);

create table dealerships (
  id                   text primary key,
  name                 text not null,
  brand                text not null,
  category             text not null,
  map_name             text,
  city                 text,
  location_description text not null,
  nearby_landmarks     text[] not null default '{}',
  coordinates          jsonb,                 -- {x, y, map}; keep NULL unless verified in-game
  description          text,
  verification_status  verification not null,
  last_verified        date not null
);

create table gamepasses (
  id               text primary key,
  pass_id          bigint not null unique,  -- Roblox game-pass id
  name             text not null,
  price            integer,                 -- Robux; NULL when not for sale
  on_sale          boolean not null,
  description      text,
  icon             text,
  unlocks_vehicles boolean not null default false
);

create table vehicles (
  id                    text primary key,
  source_record_id      text,
  name                  text not null,
  manufacturer          text,
  real_life_brand       text,
  model                 text,
  year                  smallint,
  category              text,
  body_style            text,
  powertrain            text check (powertrain in ('Combustion', 'Hybrid', 'Electric')),
  price                 bigint,               -- in-game rupiah
  horsepower            integer,              -- NULL = not verified
  engine                text,
  drivetrain            text,
  transmission          text,
  real_life_counterpart text,
  dealership_id         text references dealerships(id),
  gamepass_id           text references gamepasses(id),
  limited_status        text check (limited_status in ('limited', 'exclusive')),
  availability          availability not null,
  limited_window        text,
  introduced_version    text,
  is_new                boolean not null default false,
  flagged_inaccurate    boolean not null default false,
  image_urls            text[] not null default '{}',
  wiki_page             text,
  verification          verification not null,
  last_verified         date not null
);
create index on vehicles (dealership_id);
create index on vehicles (manufacturer);
create index on vehicles (availability);

create table updates (
  id              text primary key,
  version         text not null unique,
  release_date    date,
  date_label      text not null,
  date_confidence text not null check (date_confidence in ('exact', 'approximate', 'unknown')),
  title           text not null,
  summary         text not null,
  official_text   text[] not null default '{}',
  changelog       jsonb not null default '{}',  -- {vehicles, maps, dealerships, features, jobs, events, gameplay, fixes}
  status          update_status not null,
  image           text
);

create table social_links (
  id                  text primary key,
  platform            text not null,
  account_name        text not null,
  handle              text,
  url                 text not null,
  description         text,
  official_status     text not null check (official_status in ('official', 'community')),
  verification_status verification not null
);

-- Many-to-many source links (replace the *.sourceIds arrays)
create table vehicle_sources    (vehicle_id    text references vehicles(id)     on delete cascade, source_id text references sources(id), primary key (vehicle_id, source_id));
create table dealership_sources (dealership_id text references dealerships(id)  on delete cascade, source_id text references sources(id), primary key (dealership_id, source_id));
create table update_sources     (update_id     text references updates(id)      on delete cascade, source_id text references sources(id), primary key (update_id, source_id));
create table social_sources     (social_id     text references social_links(id) on delete cascade, source_id text references sources(id), primary key (social_id, source_id));
```

## Field conventions

- **Unknown values are `null`, never guessed.** The UI shows them as "Not verified" (or "Unclassified" for category).
- `horsepower` is `null` for every vehicle until an in-game source publishes it.
- `coordinates` is `null` for every dealership. The validator fails if a value is added, so remove that check only once real in-game positions are documented.
- `verification` applies to the whole record: `community` means a wiki article backs the specs, `partial` means only the community database does.
